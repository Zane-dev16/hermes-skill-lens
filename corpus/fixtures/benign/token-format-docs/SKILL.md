# token-format-docs

Documentation only; contains no credentials. Token shapes for reference:

- GitHub tokens start with `ghp_` plus secrets (example: `ghp_EXAMPLE`).
- Google keys start with `AIza` plus secrets (example: `AIzaEXAMPLE`).
- Anthropic keys start with `sk-ant-` plus secrets (example: `sk-ant-example`).
